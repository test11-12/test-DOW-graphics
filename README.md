# test-DOW-graphics

## Films

[`films/`](films/README.md) holds three narrated, simulated visualizations of 2026 defense-tech firsts —
the Hermeus Quarterhorse Mk 2.1 supersonic flight, the Anduril YFQ-44A Fury's first AMRAAM shot, and the
Saronic Corsair strike at Bandar Abbas — each as a playable page, a rendered MP4 and a storyboard.
They are simulations built from public reporting, not footage.
